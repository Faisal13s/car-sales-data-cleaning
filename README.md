# Car Sales Data Cleaning Project

## Project Overview
This project focuses on cleaning and validating car sales data using Python and Pandas.

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook

## Data Cleaning Process
- Handled missing values.
- Removed duplicate records.
- Checked invalid prices and mileage values.
- Validated model years and data consistency.
- Prepared the cleaned dataset for further analysis.

## Results
- Final dataset: 43 rows and 16 columns.
- Missing values: 0.
- Duplicate rows: 0.
- Invalid prices: 0.
- Invalid mileage values: 0.
- Invalid model years: 0.

## Files
- `HW3_CarSales_Faisal1.ipynb`: Notebook containing the cleaning and validation code.
- `car_sales_cleaned (3).csv`: Cleaned dataset.
